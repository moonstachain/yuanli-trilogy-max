# 原力叙事四拍九段

> 本文是这座知识库「表达系统的自述」，也是全库五十余篇的格式正典：每一篇模块叙事都按本文的九段落笔，每一篇变体都从本文的模板派生。姊妹篇[叙事质量标准与禁区](72-叙事质量标准与禁区.md)负责判，本文负责写。

## 1. 核心公式：四拍如何长出九段

原力叙事的核心公式不变：

> **原力叙事 = 心智隔离 × 小切口 × 大纵深 × 新植入 × 高弧光 × 可回写**

四拍是心法：心智隔离腾空旧抽屉，小切口打开人，大纵深说服人，新植入改变人，高弧光照亮人。乘号意味着任何一项为零、整篇为零。

但心法落到一座**成体系的知识库**里，四拍必须展开成可施工、可质检的段落结构。v1（trilogy-narrative）用七段承载四拍；本库（max 版）升级为**九段**——四拍占五段，新增的三段（深潜导流、递归回写、自诊三问）承载「可回写」这个此前只存在于公式尾巴上的因子。九段与四拍的对应：

| 拍 | 段 |
|---|---|
| 心智隔离 | ①旧认知隔离 |
| 小切口 | ②小切口 |
| 大纵深 | ③大纵深 |
| 新植入 | ④新植入 ＋ ⑤深潜导流 |
| 可回写 | ⑥递归回写 ＋ ⑦自诊三问 |
| 高弧光 | ⑧高弧光 ＋ ⑨金句与源置信度 |

## 2. 标准九段逐段规范

模块篇（A1–A4、B1–B4、C1–C4 共十二篇）是本库的主力篇型，标准九段如下。每段给出任务与合格判据——判据即质检线，不达即打回。

### ① 旧认知隔离

从正典 04d 该模块的**「不是它”字段**出发，写 4 组「很多人以为 X 是___，但 X 不是___」，外加 1 个**最隐蔽的反例**——那种连聪明人都会中招的误解，通常是「方向对了但尺度错了」或「要素全对但关系错了」的形态。

**合格判据**：四组隔离全部溯源自「不是它」字段而非临场发挥；隐蔽反例读来有「被点名」的刺痛感；语气是「那个抽屉太小」，不是「你以前全错了」。

### ② 小切口

**300–400 字**的一个具体场景：一个人、一个时刻、一段对话、一处细节。只负责让读者第一分钟心里冒出「这说的是我」，不负责讲完故事。

**合格判据**：有可看见的细节（时间、动作、一句原话）；抽出来单独给目标读者看，反应是「有关」而非「有意思」；字数在带内——短于 300 字热不起来，长于 400 字喧宾夺主。

### ③ 大纵深

从切口打穿到结构，固定打**历史、时代、体系**三维，**每维各带一张表**：历史维的表装周期或演化序列，时代维的表装「这一次为什么不同」的对照，体系维的表装从结构到入口的推导层级。

**合格判据**：三维三表齐全；每张表都在推进论证而非陈列材料；读完能说出「这背后的结构是___」。

### ④ 新植入

正典内容的落点，四件套零删减：正典一句话定义、**第一性问题**、**原子模块表（全量）**、**判断标准表（全量）**。两张表来自 04d，一行都不许裁——这是本库区别于任何二创转述的硬承诺。

**合格判据**：两表与正典逐行对得上；第一性问题原文照录；定义可复述——读者第二天能一句话转述给别人。

### ⑤ 深潜导流

约 **200 字**，指向本卷对应的深潜篇。任务是诚实交代「本篇为读性做了压缩，全量展开在哪里」，并给出一个让人想深潜的钩子问题。

**合格判据**：链接指向本卷真实存在的深潜篇；钩子是问题不是广告语。

### ⑥ 递归回写

写明**本模块的输出物写回哪个模块**——A 线的输出如何成为 B 线的输入，B 线的战果如何回灌 A 线的母体，C 线如何把一切行动固化为系统。挂接[十二模块递归回写图](../50-spine/52-十二模块递归回写图.md)。

**合格判据**：回写目标是具体模块编号而非泛泛的「体系」；与 frontmatter 的 `rewrites-to` 键一致。

### ⑦ 自诊三问

**3 个 yes/no 问题**，帮读者判断自己是否正卡在本关。接[自诊·你卡在哪一关](../50-spine/53-自诊-你卡在哪一关.md)。

**合格判据**：三问都能用「是/否」干脆作答；答「否」的组合能指出去处（前一关未过、或该进下一关）。

### ⑧ 高弧光

拉回[母公理ʸx](../00-canon/02-母公理ʸx.md)升维收束：本模块讲的方法，本质是母公理在这一格的投影；落点在人不在术——写给那个「最初出发的人」。

**合格判据**：删掉此段全文会塌（伪弧光删掉反而更完整）；主语是「你」。

### ⑨ 金句与源置信度

2–4 句可独立传播的金句（总装阶段汇入[金句总表](73-金句总表.md)），加一行源与置信度声明，与 frontmatter 呼应。

**合格判据**：金句脱离上下文仍成立；置信度声明诚实（见[内容契约](../80-governance/81-内容契约.md)）。

## 3. 五种变体模板

九段是模块篇的满配。其余篇型按职能裁剪：

| 变体 | 结构 | 篇幅 | 适用 |
|---|---|---|---|
| **卷首** | ①②⑧⑨ ＋ 弧光预告 ＋ 本卷 4 模块导航 | ~1500 字 | 三卷各一篇（10/20/30 卷首） |
| **深潜篇** | 九段去①，④换成**全量展开**，尾部加回母模块链 | 2500–3000 字 | 各卷深潜（15–17、25–28、35–38） |
| **案例篇** | 四关通关叙事：入场 → 卡点 → 关键一战 → 回写 | 不限 | 60-cases（脱敏或 design-fiction） |
| **贯穿篇** | 定义 → 三卷显形（在 A/B/C 各长什么样）→ 判断标准 → 金句 | ~1200 字 | 05-threads 五条贯穿概念 |
| **龙骨/脊骨** | 论证体：①③④⑧⑨（免切口，直接立论） | 不限 | 00-canon、50-spine |

变体的原则：**砍段不砍拍**——无论砍到几段，心智隔离的分寸、纵深的结构感、植入的正典忠实、弧光的价值复位，一个都不能松。

## 4. Frontmatter 契约

全库统一，缺键即不合格：

```yaml
title: 篇名
module: A1…C4 / method / governance / canon / thread / case / spine
layer: asset / venture / os / canon / threads / spine / cases / method / governance
type: module / volume-intro / deep-dive / case / design-fiction / thread / canon / method-canon / governance
sources:          # 逻辑指针，不写绝对路径
  - soul/extracts/04d-四四四原子级正典体系-v0.8#B1
confidence: 🟢 / 🟡（可分字段声明，如「正典字段🟢 / 案例细节🟡」）
```

模块篇另加两个必备键：

```yaml
threads: [T1, T2]      # 本篇引用了哪些贯穿概念（05-threads）
rewrites-to: B1        # ⑥递归回写的目标模块，与正文一致
```

## 5. 与 v1 七段的差异及升级理由

v1 七段 = 隔离、切口、纵深、植入、弧光五段照打，「完整版本」由文档本身承担，末段金句与置信度。max 九段在其上做了三处结构化收紧（①的四组+隐蔽反例定量化、③的三维三表定型、④的两表零删减入约），并**新增⑤⑥⑦三段**。新增不是加量，每一段都有第一性理由：

- **⑤深潜导流 = 完备性**。九段模块篇为可读性必须压缩，压缩若不声明去处，就是对正典的静默裁剪。深潜篇承接全量，导流段承认压缩——完备性由「模块篇＋深潜篇」的双层结构共同兑现，而不是靠单篇硬塞。
- **⑥递归回写 = 递归性**。母公理ʸx说：任何输出若不能成为下一次的输入，就不是原力资产。v1 把「可回写」留在公式里，篇内无处安放；max 给它一个固定段位，逼每一篇当场回答「我写回哪里」。方法论自身先过母公理，才有资格讲母公理。
- **⑦自诊三问 = 可用性**。知识库最常见的堕落是「读完都对，合上没用」。三个 yes/no 把每一篇从「被阅读的文本」变成「被使用的工具」——读者不只是理解这一关，而是当场判断自己是否卡在这一关。

一句话总结升级逻辑：**v1 让每一篇写得对，max 让整座库转得动**——深潜保证不缺、回写保证成环、自诊保证被用。

## 6. 施工顺序建议

写一篇模块篇的推荐顺序不是①到⑨，而是：先④（锁定正典四件套）→ 再①（从「不是它」字段取隔离）→ 再②③（为植入配切口与纵深）→ 再⑥⑦（想清回写与自诊）→ 最后⑤⑧⑨。先立骨、再生肉、后点灯——顺序错了，最常见的结果是切口精彩而植入漂移。

写完之后，进[叙事质量标准与禁区](72-叙事质量标准与禁区.md)过检。
