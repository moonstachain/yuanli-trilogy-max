## 2. A 轴教学动作唯一映射

| 正典模块 | 教学动作 | 跨时代第一性问题 | 状态迁移 |
|---|---|---|---|
| A1 发现母体 | **找源** | 什么持续生成我的不同？ | 表层能力 / 标签 / 事件碎片 → 母体候选 |
| A2 回到母体 | **归源** | 哪些东西真正属于我，哪些只是外界塑造？ | 母体候选 → 经校准的母体 |
| A3 获得原力 | **炼源** | 如何把潜在生成结构训练成真实能力？ | 经校准母体 → 可调用原力 |
| A4 显化原力 | **证源** | 这种原力进入真实世界后，是否真正创造价值？ | 可调用原力 → 经现实选择初步验证的原力资产 |

正式裁决：

```text
找源 / 归源 / 炼源 / 证源 = 教学动作词、生成链词。
发现母体 / 回到母体 / 获得原力 / 显化原力 = 正典模块名。
教学动作不得替换模块法权。
```

旧问题的正确层级：

```text
AI 清算之后还剩什么？ = A1 时代教学钩子
什么保留、什么停止？ = A2 操作层问题
五种能力如何外化？ = A3 表现层问题
这个原力是否被世界需要？ = A4 教学钩子
```

## 3. 原力母体与原力资产

| 术语 | 正确用法 |
|---|---|
| **原力母体** | 持续生成判断、作品、关系和意义的底层生命结构；整套原力战略的生成第一因 |
| **原力资产** | 母体经过发现、校准、训练与真实世界验证后形成的可调用、可训练、可验证、可复用差异价值；第一部终态 |

禁止：

```text
把“原力母体”写成第一部名称。
把“原力母体”与“原力资产”当同义词。
把MBTI、人格原型、职业优势、兴趣或单一高能事件直接宣布为母体。
```

## 4. B4 四大壁垒唯一口径

此前本仓保留过“六层壁垒”的历史材料。该表达现已废止。

| 正名 | 控制权 | 典型组成 |
|---|---|---|
| **虚壁垒** | 心智控制权 | 认知、品牌、意义、叙事、品味、信任、母体心智垄断 |
| **实壁垒** | 交付控制权 | 产品、方法、工具、数据、流程、供应链、案例库、AI工作流 |
| **入壁垒** | 入口控制权 | 内容、渠道、社群、关系、转介绍、口碑、网络效应、信任飞轮 |
| **出壁垒** | 留存控制权 | 复购、迁移成本、身份绑定、习惯、数据沉淀、长期关系、共同建设 |

```text
飞轮 = 四大控制权相互强化的机制，不是第五类壁垒。
母体 = 四大控制权持续生成差异的源头，不是第六类壁垒。
```

“16控制点”仍可作为四类壁垒的细化工具，每类四个控制点；它不改变四类本体。

## 5. 禁用词对照

| 禁用写法 | 正名 / 正确用法 | 裁决理由 |
|---|---|---|
| 第一部 = 原力母体 | 第一部 = **原力资产** | 母体是第一因，资产是第一部终态 |
| 找源 / 归源 / 炼源 / 证源作正式模块名 | 正式场合仍用 A1-A4 正名 | 四词是教学动作，不是新模块 |
| A1第一性问题 = AI清算后还剩什么 | A1 = **什么持续生成我的不同？** | AI问题是时代钩子，不是跨时代第一性问题 |
| A2第一性问题 = 什么保留/停止 | A2 = **哪些东西真正属于我，哪些只是外界塑造？** | 保留/停止是操作层 |
| A4第一性问题 = 世界是否需要 | A4 = **是否真正创造价值？** | “被需要”可停留在口头喜欢，价值需行为和结果证据 |
| 「原力觉醒」作 B1 模块名 | B1 正名 = **原力借势** | 觉醒语汇归 A 线人生课题域 |
| 「借势合力」作 B1 模块名 | 借势合力 = **财富公式名** | 公式统摄第二部，不等于 B1 |
| 「模式升级」作 B3 模块名 | B3 正名 = **模式升维** | “升维”强调商业容器量级变化 |
| 六层壁垒 / 飞轮壁垒 / 母体壁垒作并列分类 | **虚 / 实 / 入 / 出四大壁垒** | 飞轮是机制，母体是源头 |
| 「灵魂 / 记忆 / 判断 / 手脚」作 C 线正式标题 | 一纸文脉 / 一个大脑 / 一张地图 / 一条链路 | 隐喻可括注，不能替换正名 |

## 6. 关键概念正名

| 正名 | 定义锚 |
|---|---|
| ʸx（母公理） | 做会自我繁殖的事，不做一次性的事 |
| 总飞轮 | 母体 → 原力资产 → 原力创业 → 原力OS → 母体升级 ⟲ |
| 递归回写 | 贯穿十二模块的运行机制：每次结果成为下一次输入，不是独立第五步 |
| 概念原子 | 进入正典的最小格式：ID/名称/归属/定义/不是它/第一性问题/输入/判断/输出/接口/回写 |
| 创业输入包 | A4 → B1 的接口物：天选用户、贵问题、心理账户线索、行为证据、结果观察与未知 |
| OS回写包 | B4 → C1-C4 的接口物：四大控制权、控制点、案例、规则与需保留的经营经验 |
| 天选用户 | 最自然被原力吸引、并能从中获得真实改变的人群 |
| 贵问题 | 不解决代价足够高，值得投入预算、注意力与行动的问题 |
| 利润容器 | B3 产物：可持续交付、获利、复制并再投资的商业系统 |
| 财富飞轮 | 四大控制权在持续运行中的自增强结果；不是独立壁垒类别 |
