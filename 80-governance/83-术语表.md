## 2. 禁用词对照

| 禁用写法 | 正名 / 正确用法 | 裁决理由 |
|---|---|---|
| 「原力觉醒」作 B1 模块名 | B1 正名 = **原力借势** | 觉醒语汇归 A 线人生课题域（原力资产/人侧正典），不再作创业四关首关名 |
| 「借势合力」作 B1 模块名 | 借势合力 = **财富公式名**（财富 = 借势 × 合力） | 公式统摄整个第二部，不等于第一步；见 [03-财富公式](../00-canon/03-财富公式-借势乘合力.md) |
| 「模式升级」作 B3 模块名 | B3 正名 = **模式升维** | 04d 正典定名「升维」——量级切换，不是同级优化 |
| 「灵魂 / 记忆 / 判断 / 手脚」作 C 线标题 | 只可作括号注释，如「一纸文脉（灵魂）」 | C 线四器官是本质隐喻，标题一律用「一纸/一个/一张/一条」正名 |
| 「觉醒 / 独创 / 升维 / 锁定」四字缩写作正式模块名 | 正式场合用 B1–B4 全名 | 缩写仅限行文中已出现全名后的复指 |
