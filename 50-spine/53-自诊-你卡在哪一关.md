# 自诊：你卡在哪一关

> 这不是性格测试，也不是“哪章没读懂就重读”的阅读指南。它是一张**事业断点定位表**：从十二模块第一性问题出发，找到当前最靠前、最影响后续结果的断点。

核心纪律：

> **症状往往在下游发作，病灶可能在上游。第一个你无法用真实证据回答的模块，就是优先检查点。**

---

## 1. 先定卷：自我、世界、时间

### A 卷 · 原力资产

如果你最常出现的是：

```text
我有很多能力，却说不清什么真正不可复制；
知道一点自己，但选择仍被机会和外界牵着走；
知道自己，却无法稳定形成作品、方法和能力；
有能力，却不知道它是否真的创造价值。
```

先进入 A 卷。

### B 卷 · 原力创业

如果你已经拥有可验证的原力输入，却出现：

```text
不知道为什么偏偏现在做；
用户听不懂你究竟是什么；
有人买，但越成功越忙、模式不复制；
生意跑通，却没有长期控制权。
```

先进入 B 卷。

### C 卷 · 原力OS

如果你已有真实业务，却出现：

```text
AI和团队总把你做变形；
过去经验反复丢失；
知道很多，却不知道该优先建设什么能力；
做了很多任务，却没有真实Outcome和下一次复用。
```

先进入 C 卷。

三个都中？从最上游的断点开始。

## 2. A 组：找源—归源—炼源—证源

| ID | 第一性问题 | 证据标准 | 答不出来去哪里 |
|---|---|---|---|
| **A1 找源** | **什么持续生成我的不同？** | 至少能给出跨时间证据、反证与未知，而不是一个人格/职业标签 | [A1 发现母体](../10-yuanli-asset/11-A1-发现母体.md) |
| **A2 归源** | **哪些东西真正属于我，哪些只是外界塑造？** | 能区分母体生成、适应能力、路径惯性、外部塑形，并指出真实取舍 | [A2 回到母体](../10-yuanli-asset/12-A2-回到母体.md) |
| **A3 炼源** | **如何把潜在生成结构训练成真实能力？** | 有调用条件、质量阈值、失败边界，以及重复调用/修订证据 | [A3 获得原力](../10-yuanli-asset/13-A3-获得原力.md) |
| **A4 证源** | **这种原力进入真实世界后，是否真正创造价值？** | 区分弱信号、真实行为、结果观察；不知道时敢写 `not_observed` | [A4 显化原力](../10-yuanli-asset/14-A4-显化原力.md) |

### A1 常见误诊

```text
“我是INTJ / 智者型。” → 标签，不是母体证据。
“我会战略。” → 技能/职业表型，不是生成源。
“AI做不了我这个活。” → 可能只是暂时工具边界，不等于母体。
```

### A2 常见误诊

```text
“我做这个很高能，所以一定属于我。” → 高能只是线索。
“外部期待都不是我。” → 外部塑形也可能形成有价值的适应能力。
“我写了不再做清单。” → 没有真实取舍与代价，不算完成。
```

### A3 常见误诊

```text
“AI帮我写得很好。” → 可能是模型能力。
“我做出一个代表作。” → 一次高光不能证明稳定能力。
```

### A4 常见误诊

```text
“很多人点赞。” → L0弱信号。
“有人说愿意买。” → 仍不是发生过的付款。
“产品页上线。” → 文件存在，不等于用户Outcome。
```

## 3. B 组：时代—心智—模式—控制权

| ID | 第一性问题 | 证据标准 | 答不出来去哪里 |
|---|---|---|---|
| B1 | **这个时代为什么现在需要我？** | 能说清时代变化、贵问题升值、母体匹配与入场窗口 | [B1 原力借势](../20-yuanli-venture/21-B1-原力借势.md) |
| B2 | **市场如何认得我？** | 用户能用自己的语言理解、记住、比较、转述，并有真实预算/行为线索 | [B2 品类独创](../20-yuanli-venture/22-B2-品类独创.md) |
| B3 | **如何持续赚钱、可复制？** | 前链、后链、财链能形成可持续价值交换，不只卖创始人时间 | [B3 模式升维](../20-yuanli-venture/23-B3-模式升维.md) |
| B4 | **如何守住、不被拿走？** | 能指出自己实际掌握的心智、交付、入口、留存控制权 | [B4 壁垒锁定](../20-yuanli-venture/24-B4-壁垒锁定.md) |

### B4 四权快速诊断

```text
虚壁垒 / 心智控制权：用户是否越来越用你的语言理解问题？
实壁垒 / 交付控制权：结果是否越来越依赖沉淀系统而非临时英雄主义？
入壁垒 / 入口控制权：新用户是否持续通过可控入口进入并形成信任？
出壁垒 / 留存控制权：老用户是否因成果、数据、关系、习惯与共建持续留下？
```

飞轮是四权相互强化的机制；母体是四权持续生成差异的源头。**不要再用“六层壁垒”分诊。**

## 4. C 组：主权—证据—能力—现实闭环

| ID | 第一性问题 | 证据标准 | 答不出来去哪里 |
|---|---|---|---|
| C1 | **这次任务必须坚持什么、不能牺牲什么、谁有权决定什么？** | 有经人批准的最小身份、意图、品味、边界与授权上下文 | [C1 一纸文脉](../30-yuanli-os/31-C1-一纸文脉.md) |
| C2 | **面对这次任务，我们已经知道什么，证据有多可靠？** | 事实、知识、案例、失败、决策与Outcome有来源、版本和可信度 | [C2 一个大脑](../30-yuanli-os/32-C2-一个大脑.md) |
| C3 | **事业必须具备哪些能力，当前应优先改变哪一个？** | 能在CBM能力本体上定位瓶颈、控制点、成熟度与优先级 | [C3 一张地图](../30-yuanli-os/33-C3-一张地图.md) |
| C4 | **任务如何从判断进入行动，并以真实结果改变下一次行动？** | 有 WPK → ACT → OUT → LRN，并有第二任务事前加载/复用证据 | [C4 一条链路](../30-yuanli-os/34-C4-一条链路.md) |

C 线最常见的假绿：

```text
文档生成了 ≠ Action发生了
Agent跑了 ≠ Outcome成立
规则写进库 ≠ 下一任务真的复用了
```

## 5. 最短分诊口诀

```text
不知道什么在持续生成你的不同 → A1 找源
知道候选，但分不清生成与塑形 → A2 归源
知道自己，但不能稳定调用 → A3 炼源
有能力，但价值证据不够 → A4 证源

有价值，但不知道为什么现在做 → B1
时代对了，但用户认不出 → B2
用户认了，但越做越累/不赚钱 → B3
模式跑了，但控制权没留下 → B4

团队/AI总做变形 → C1
过去经验总丢 → C2
不知道先建什么能力 → C3
判断没有进入真实行动与复用 → C4
```

## 6. 诊断结果必须生成下一步动作

自诊不是为了得到一个编号。

每个诊断至少留下：

```text
当前断点
支持证据
反证 / 未知
最小下一步任务
成功/失败判据
回写位置
```

如果自诊只让你“更了解自己”，却没有改变下一步任务，它仍然不是原力系统的一部分。

---

## 7. 高弧光

真正好的诊断，不是告诉你哪里不够好。

而是让你看见：

> **你现在所有下游的混乱，可能只是某个更上游问题一直没有被诚实回答。**

从最早的断点开始修。因为一条传动链的速度，从来不是由最快的齿轮决定，而是由第一个打滑的齿轮决定。
