# 深潜 · 五层架构与六轴评分

> 母模块 [C2 · 一个大脑](32-C2-一个大脑.md)讲的是一个人的记忆系统怎么立起来。本篇把镜头拉远：当这颗大脑开始同时服务你、你的团队和你的 AI 班底，它必须长成一套完整的操作系统——本篇是那套系统的工程图纸：五层解耦、三类接口、六轴体检、四阶段路线。开读前先收下诚实声明：图纸本身有正典依据，但它描述的是一套仍在施工的系统，落地尚未成熟。

## 一、为什么需要「操作系统」而不是「工具集」

一个创业者的真实需求从来不是单点的：战略诊断、财务建模、内容生产、客户交付，全链路都要。如果每个环节配一个独立工具，他很快会发现自己成了「工具管理专家」——工具越多，接缝越多，接缝里漏掉的全是他的时间。

原力OS 的回答是换范式：不做更多工具，做让工具协同的平台。就像操作系统之于程序——它自己不干具体的活，它让干活的各方在同一套规矩下工作。这个选择背后有一个被反复验证的判断：**系统架构的价值不亚于模型能力本身**——模型人人一样，输赢在装模型的那副骨架。

## 二、五层解耦：把四件事拆开

骨架的第一原则是解耦：把「入口体验、治理真相、执行能力、协作分发」从一团混合物里拆开。五层自上而下：

| 层 | 装什么 | 职责边界 |
|---|---|---|
| 交互入口层 | 对话入口、IM、CLI、移动端 | 只做传声筒，不做业务逻辑 |
| 治理与调度层 | AI 大管家（治理核） | 意图解析、路由、验真、闭环 |
| 执行能力层 | 技能、浏览器、多 agent | 干活，且只通过统一接口干活 |
| 基础服务层 | 模型路由、记忆存储、事件总线 | 供水供电，不问业务 |
| 镜像协作层 | 协同文档、代码托管平台 | **只做镜像，不做真相源** |

最后一行是全架构最锋利的一条铁律：**本地结构化数据是唯一真相源（canonical），一切外部平台只是 mirror**。任何前台聊天、群消息都不能直接升格为正式记忆，必须经治理层审查归档。多数 AI 工作流的溃败都从「聊天记录和正式数据分叉」开始——这条铁律就是 C2 索引层与版本层，在系统级的放大。

在能力栈的切面上，同一套系统还可以按技能职责切成另外五层：L0 递归层（心跳引擎，只管进化不管业务）、L1 战略层、L2 工具层、L3 业务层、L4 场景层——上层编排下层，L0 在暗处记录每一轮的有效模式与浪费模式。两种五层不冲突：前者按系统职责纵切，后者按能力层级横切。

## 三、三类标准接口：解耦靠硬隔离，不靠画图

分层图人人会画，让分层成立的是三类硬性接口：**前台接口**（面向入口的轻量请求与状态回复）、**治理接口**（任务生命周期、路由决策、验真状态、人类边界、闭环状态——治理层对外的唯一通道）、**执行接口**（技能与工具的统一调用与审计回写）。

三类接口共同守一个反模式：绕过治理层的任何直连都不被允许。这让每一次执行都有审计痕迹、每一份记忆都有来路——大脑判断标准里那句「是否可信」，在系统级靠的就是这三道闸。

## 四、六轴评分：给整个系统做体检

一个自称「会进化」的系统，必须能被打分证伪。六轴模型给整个 OS 做定期体检：

| 轴 | 检查什么 |
|---|---|
| 主题层 | 选的仗对不对 |
| 策略层 | 打法赢不赢得了 |
| 执行层 | 实际跑起来没有 |
| 递归进化 | 每次是否变强 |
| 全局最优 | 是否局部优化害全局 |
| 人类友好 | AI 介入边界是否清晰 |

每轴五个检查点、每点 0/1/2 分，总分六十，等级从 A 到 D。配套一条打分纪律：每个分数必须同时给出怎么得来的、扣在哪、证据是什么、下一步怎么改——**不允许黑箱打分**。

六轴对 C 线的意义在于自反性：C3 说系统要有决策阈值，六轴就是给系统自己画的阈值——它把「我的 OS 健康吗」从感觉题变成证据题。低于线的轴，就是下一轮进化的靶子。

## 五、四阶段路线：先硬化，再复制

图纸最后一页是施工顺序，四个阶段严格串行：

| 阶段 | 核心目标 | 一句话判据 |
|---|---|---|
| 前台壳稳定期 | 先跑起来 | 轻路由、轻知识、轻记录不掉链 |
| 统一后脑期 | 治理闭环 | 真相源、证据、技能三件套打通 |
| 可插拔能力网络期 | 能力扩展 | 新能力即插即用且留审计 |
| 克隆工厂期 | 规模复制 | 一套治理核服务多个隔离实例 |

不许跳级的理由和 B 线不跳关同构：**过早扩展等于复制半成品**——治理没硬化就克隆，是把 bug 连同架构一起量产。第四阶段有显式门槛：治理成熟度过线才准启动。这四步走完，一个人的大脑才真正长成了「个人脑 / 企业脑」双层结构的地基。

## 八、自诊三问

1. 你的系统里，「正式记忆」和「聊天记录」有显式的边界和晋升通道吗？
2. 你能给自己的 OS 打出一张带证据的六轴分数表吗——还是只有「感觉还行」？
3. 你现在处于四阶段的哪一段——你的扩张动作和这个阶段匹配吗？

第 1 问答「否」，真相源正在分叉，先立 canonical 铁律；第 2 问答「否」，你的系统不可证伪，从六轴自评开始；第 3 问错配（治理未硬化就想复制），停下扩张先补后脑。完整分诊见[自诊 · 你卡在哪一关](../50-spine/53-自诊-你卡在哪一关.md)。

## 九、高弧光

架构图看起来是最冷的东西——五个框、三根线、一张评分表。但你顺着它想一层就会发现，每条铁律都在保护一个很热的东西。

真相源唯一，保护的是「你说过的话不被系统偷换」；治理接口唯一，保护的是「没有一次执行绕过你的规矩」；六轴不许黑箱，保护的是「系统好不好，证据说了算，不是它自己说了算」。所谓工程，就是把信任写成结构。**你不必相信系统的善意——你只需要检查它的架构：一套让越界变得困难的结构，比一万句忠诚的承诺更配得上托付。**
