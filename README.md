# 原力战略三部曲 · 叙事知识库-max

> 一条公理 `ʸx`，三部书，五十五篇。
> 讲清 AI 时代一个人如何把**不可复制的自己**，变成**可繁殖的事业资产**。
>
> 标准：**究竟**（第一性）· **完备**（原子模块零删减）· **递进**（一条阅读动线打穿）· **原子**（一篇一概念、可独立引用）。
> 表达：**原力叙事四拍九段**（心智隔离 × 小切口大纵深 × 新植入 × 高弧光，展开为九段），见 [70-method/71](70-method/71-原力叙事四拍九段.md)。

母公理 **`ʸx`**：**做会自我繁殖的事，不做一次性的事。**

这套体系的第一因不是“AI”，也不是某个技能，而是**原力母体**：一个人持续生成独特判断、作品、关系与意义的底层生命结构。第一部不叫“原力母体”，仍然叫**原力资产**——因为第一部真正完成的是把这个生成源加工成可调用、可训练、可验证、可复用的资产。

---

## 一、这个仓在讲什么

AI 正在清算一切「同质化能力」的定价基础。会写、会算、会画、会搜、会做标准分析，越来越不稀缺。真正稀缺的是：

> **什么持续生成你的不同？**

三部曲回答三个递进问题：

| 卷 | 一句话 | 第一性问题 | 四个模块 |
|---|---|---|---|
| **第一部 · 原力资产**（A线·自我） | 找到你，并把“你”炼成资产 | 差异价值从哪里持续生成？ | 发现母体 → 回到母体 → 获得原力 → 显化原力 |
| **第二部 · 原力创业**（B线·世界） | 让世界认出并放大你 | 这种差异如何进入时代、市场与价值交换？ | 原力借势 → 品类独创 → 模式升维 → 壁垒锁定 |
| **第三部 · 原力OS**（C线·时间） | 让每次结果都让下一轮更强 | 已产生的价值如何跨时间保存、调用与升级？ | 一纸文脉 → 一个大脑 → 一张地图 → 一条链路 |

三卷不是并列，而是一个总飞轮：

```text
原力母体
→ 原力资产
→ 原力创业
→ 真实经营结果
→ 原力OS
→ 母体升级 ⟲
```

走完一圈，你不只是做成了一件事，而是**变成了更能做成下一件事的人**。

## 二、第一部最新阅读脊柱：找源—归源—炼源—证源

第一部四个正典模块名称不变；新增的是一套帮助读者理解“这一步究竟在做什么”的教学动作。

| ID | 正典模块 | 教学动作 | 跨时代第一性问题 |
|---|---|---|---|
| A1 | 发现母体 | **找源** | **什么持续生成我的不同？** |
| A2 | 回到母体 | **归源** | **哪些东西真正属于我，哪些只是外界塑造？** |
| A3 | 获得原力 | **炼源** | **如何把潜在生成结构训练成真实能力？** |
| A4 | 显化原力 | **证源** | **这种原力进入真实世界后，是否真正创造价值？** |

四个动作不是四个新模块，而是一条状态迁移：

```text
表层能力 / 标签 / 事件碎片
→ 母体候选
→ 经校准的母体
→ 可调用原力
→ 经现实选择初步验证的原力资产
```

AI 在第一部的正确位置是**镜子、训练器、外化器与放大器**，不是原力资产的本体，也不拥有“你真正是谁”的裁决权。

4. **教学动作不抢法权**：找源 / 归源 / 炼源 / 证源用于帮助读者理解，但 A1-A4 正典模块名始终不变。
