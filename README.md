# 原力战略三部曲 · 叙事知识库-max

> 一条公理 `ʸx`，三部书，五十五篇。
> 讲清 AI 时代一个人如何把**不可复制的自己**，变成**可繁殖的事业资产**。
>
> 标准：**究竟**（第一性）· **完备**（原子模块零删减）· **递进**（一条阅读动线打穿）· **原子**（一篇一概念、可独立引用）。
> 表达：**原力叙事四拍九段**（心智隔离 × 小切口大纵深 × 新植入 × 高弧光，展开为九段），见 [70-method/71](70-method/71-原力叙事四拍九段.md)。

母公理 **`ʸx`**：`y` 是你能做的事，`x` 是你能借的势，指数位上的 `你` 决定这件事到底是消耗还是资产——**做完就归零的事是消耗，做完会生出下一件的事，才是资产**。三部书就是这条公理在**人 / 事 / 法**三面墙上的三次投影。

---

## 一、这个仓在讲什么

AI 正在清算一切「同质化能力」的定价基础。会写、会算、会画不再稀缺——稀缺的是**那个只有你能生成差异的底层结构**。三部曲回答三个递进的问题：

| 卷 | 一句话 | 第一性问题 | 四个模块 |
|---|---|---|---|
| **第一部 · 原力资产**（A线·人） | 找到你 | AI 清算之后，你还剩什么？ | 发现母体 → 回到母体 → 获得原力 → 显化原力 |
| **第二部 · 原力创业**（B线·事） | 变现你 | 时代为什么现在需要你？ | 原力借势 → 品类独创 → 模式升维 → 壁垒锁定 |
| **第三部 · 原力OS**（C线·法） | 系统你 | 如何让每次行动回写成下一次能力？ | 一纸文脉 → 一个大脑 → 一张地图 → 一条链路 |

三卷不是并列，而是一个**总飞轮**：母体 → 原力 → 市场 → 生意 → OS → 母体升级 ⟲。走完一圈，你不只是做成了一件事，而是**变成了能做成下一件事的人**。
