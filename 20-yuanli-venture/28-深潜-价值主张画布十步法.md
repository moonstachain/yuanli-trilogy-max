# 深潜 · 价值主张画布十步法

> 母模块 [B2 · 品类独创](22-B2-品类独创.md)给了三角定位公式，本篇是它的施工手册：价值主张画布的十步落地，前接甜用户识别，后通心智独占。画布原法源自公开方法论（价值主张画布与「用户任务」理论），课程把它改造成了品类独创的施工图——本篇按改造后的口径展开。

## 一、一次成功的访谈，一无所获

一位软件行业的创始人做产品前访谈了三十位目标用户，问题清单很专业：「你需要哪些功能？」「你愿意为它付多少钱？」用户也很配合，功能列了几十条，报价也给了。产品照单做出来，试用者众，付费者寥寥。

复盘时一位老用户说了实话：「你问我要什么功能，我就替你想了些功能。但我买东西的时候，想的不是功能——我想的是下个月给老板汇报时，别再出上次那种丑。」

三十场访谈，问的全是「你要什么」，没有一场问到「你想完成什么」。这就是画布方法论的原点洞察：**用户不是要买你的产品，是要雇它去完成一件自己的任务。**成功不来自了解客户，来自理解客户想完成的任务。

## 二、画布的两面

画布把一次价值设计切成两半，强制你先画右边再画左边：

| 侧 | 板块 | 内容 |
|---|---|---|
| 用户画像（右） | 任务 | 用户在工作与生活里想完成什么 |
| | 痛点 | 完成任务前中后的烦恼与障碍 |
| | 收益 | 用户期望的结果与好处 |
| 价值地图（左） | 产品服务 | 你提供什么 |
| | 止痛方案 | 你如何消除哪些痛 |
| | 收益创造 | 你如何制造哪些收益 |

顺序即纪律：先把右侧画满并排序，再动左侧。反着来——先有产品再找问题——正是「解决方案找问题」这个最贵的创业错误的标准姿势。

## 三、先定人：甜用户 DNA

画布的第一格「选客户群体」在品类独创语境里有专门解法。甜用户的共性 DNA 公式：**多年行业积累 × 赚钱靠人肉 × 知道不对但说不清 × 有隐知识没资产 × 在新旧周期交替中焦虑**。对应五种深层心理：卖身模式的疲惫、系统缺失的恐惧、身份模糊的焦虑、被 AI 替代的不安、缺一面看清自己的镜子。

关键洞察：甜用户的痛不是「缺方法」，是**身份危机**——他说不清自己是什么。所以对他最有力的价值主张，不是给工具，是给身份。另一条铁律：甜用户定义越窄，品类独占性越强——把人群收窄到「在一个细分处境里的一类人」，你在那个窄缝里才可能是唯一。

## 四、十步全列

**第一步：任务识别。** 用「用户任务」框架挖出用户真正想完成的事。任务分四类（课程在经典三分上加了第四类）：功能任务（把事办成）、情感任务（获得某种感受）、社交任务（被如何看待）、投资任务（可量化的创收、提效、降本、避险）。同一任务在不同情境下含义不同——「订餐厅」之于约会与之于宴请新老板是两个任务。探针问题：用户雇你的产品去完成什么？他深夜搜索的是什么？

**第二步：收益识别。** 把用户期望的好处写具体，并分四级：最低收益（底线期望）、预期收益（行业默认必须有）、期望收益（说得出口的渴望）、惊喜收益（他没想到你做到的——创新藏在这一级）。收益比痛点难挖，因为痛看得见、渴望要共情。

**第三步：痛感识别。** 痛分三类并排出烈度：不良结果与缺陷（生气级）、障碍（无助级——想做但被卡住）、风险（恐惧级——担心的后果让他不敢开始）。小痛别急着丢，归类合并常出杠杆——几个相关的小痛一起解，效果乘算。

**第四步：聚焦排序。** 把任务、痛、收益各自按重要性与烈度排序，只留头部三到五项。这一步的本质是放弃：什么都想解决的价值主张，等于什么都没主张。

**第五步：能力匹配。** 列出你的产品与服务（含支持性服务），按「必需—锦上添花」排序，与右侧的头部任务对齐。对不上的能力再得意也先搁置——画布不关心你会什么，只关心用户雇什么。

**第六步：快速止痛。** 逐条写下你的方案如何消除头部痛点：省钱？省时间？消除障碍？打消恐惧？止痛务必具体到「用户能复述」的程度。

**第七步：量化收益。** 逐条写下你如何制造头部收益，能上数字就上数字——为多少、快多少、省多少。量化不了的收益，在成交桌上没有座位。

**第八步：完成契合。** 把左右两侧对齐检查：头部的痛都有止痛方案吗？头部的收益都有创造机制吗？你不必解决所有痛——但战略上重要的缺口要么补，要么明确放弃。契合分三层递进：问题—方案契合（右侧有证据）、产品—市场契合（市场真的买单）、商业模式契合（能规模化地赚钱）——恰好对应原型、价值、增长三重假设的验证次序。

**第九步：一句入脑。** 把契合结果压成一句标准句：**我们帮助【甜用户】在完成【核心任务】时，通过【减少痛苦】与【放大收益】，区别于【旧方案】。**品类独创语境下有一处关键修正——「区别于竞品」升级为「在新品类中成为唯一」：你的对手不是同行，是用户的旧解决方案（自己摸索、随便找人、什么都不做）。打磨工具是战略四问：哪些行业默认的要素该**消除**？哪些该**减少**到远低于行业？哪些该**提高**到远超行业？哪些是行业从未提供、该**创造**的？

**第十步：有效验证。** 按三段漏斗测试，层层收窄：需求验证（用户真有这些任务、痛与收益吗——关键词投放、落地页点击都是低成本探针）；供给验证（用户最想要你方案里的哪部分——让他们在功能间做取舍）；财务验证（他们真的会掏钱吗——模拟销售页比一百次口头承诺诚实）。记住画布不是一次性工作坊，是一个循环：验证结果回流第一步，重新排序。

## 五、闭环判据：心智独占的四个信号

十步走完不等于成功，成功有四个可观察的信号：

1. **甜用户自来**——目标用户初次接触品类名就说「这说的就是我」；
2. **无法比价**——用户找不到直接替代品来压你的价；
3. **复购动力**——身份转变驱动用户持续深入，而不是买完即走；
4. **口碑用你的词**——用户推荐你时，说的是你造的品类词，不是旧品类的类比。

第四个信号最硬：当用户开始用你的语言向别人解释世界，品类名就从营销资产变成了认知资产——这正是 [B4](24-B4-壁垒锁定.md) 虚壁垒的地基。一个好品类名比一个好产品更长寿：产品会迭代，定义权会沉淀。

## 八、自诊三问

1. 你能说出甜用户深夜搜索的那个问题——并且它和你白天宣传的是同一个吗？
2. 你的一句话价值主张里，用户、任务、止痛、收益、区隔五个槽位都填实了吗？
3. 过去一个月，有没有用户用你造的词向别人介绍你？

第 1 问答「否」，回第一步做任务考古；第 2 问答「否」，回第九步重压；第 3 问答「否」，别加大投放——先检查品类名是否触发「这是什么」的好奇而非「又一个」的归类，回母模块 B2 的③重读脑科学三触发。分诊入口见[自诊 · 你卡在哪一关](../50-spine/53-自诊-你卡在哪一关.md)。

## 九、高弧光

十步法看起来是画布技术，内核是一种伦理：**先理解，再主张。**它强迫你在开口推销之前，先把用户的任务、痛与渴望一格一格看清——看清到你说出他的处境时，比他自己说得还准。

到那一步，成交只是理解的副产品。用户买的从来不是你的产品，是「终于有人看见了我的任务」这件事本身。而当一群人开始用你给的词理解自己——你就不再是市场里的一个卖家，你成了那张地图上的一个地名。
