# B1 · 原力借势：找到时代替你推门的那个入口

## ① 旧认知隔离

很多人以为借势就是追风口。但原力借势不是追风口——风口的寿命只有六到十八个月，那是炒作的尺度；用炒作的尺度做人生级别的下注，等你看清风向，你已经是分母。

很多人以为借势就是蹭热点。但热点是别人议程上的浪花，你蹭上去只会被下一朵浪花盖掉；势是水面之下的洋流，它不需要你蹭，它推着一整片海在走。

很多人以为借势就是把宏观研究做厚——康波、地缘、产业报告一应俱全。但宏观叙事自嗨不是借势：判断都对，却推不出「周一早上我去敲谁的门」，那只是把焦虑格式化成了 PPT。

很多人以为看准了大势就该全力扑上去。但把母体强行塞进不适合的趋势，是借势的反面——势是真的，可它不放大你；势对力不对，乘积照样趋近于零。

最隐蔽的一种错，发生在聪明人身上：他们四层都看了，方向全对，**唯独尺度错了**——拿产业周期当元周期，拿政策窗口当时代窗口。于是在一个正确的大方向里，早入场三年成了先烈，晚入场三年成了分母。方向对不保证赢，尺度对才有窗口。

## ② 小切口

一位婚庆行业的创始人，曾经把一场婚礼的策展做到近乎艺术品。可最近三年，他的日历越来越满，账却越来越薄：结婚的人一年比一年少，同行报价一轮比一轮低，他凌晨两点还在改第三版方案，只为守住一个被压掉三成预算的单子。

某个深夜他停下来问自己：我的策展能力退步了吗？没有，反而更成熟了。那为什么十年前随手接单都赚钱，现在拼尽全力只能保本？

后来他做了一件反直觉的事：不再更努力，而是先停下来。他把团队收缩到最小，回头拆自己的能力原点——「秒懂客户想要什么，并把它极致呈现」。然后换了个问题：这个能力，现在谁最需要？他找到了一群预算充足、审美独特、市场基数十几年间涨了十倍的新客群，把整个业务重建在这个入口上。第二年，订单排满，利润率是过去的数倍。

能力一克没变。变的是他终于先问了势，再动手。

## ③ 大纵深

**历史维：用尺度淘汰假势。** 判断「这是不是势」的第一把刀是尺度——多数人败在把短周期误当长周期：

| 候选 | 时间尺度 | 判定 |
|---|---|---|
| 风口 | 6–18 个月 | 炒作噪声，不是势 |
| 政策 | 局部、随行政节奏摆动 | 只是势的放大器或抑制器 |
| 单一技术 | 数年 | 接近，但可能只是玩具或过客 |
| 产业周期 | 数年到十余年 | 康波的子周期 |
| 康波周期 | 50–60 年 | 真正的元周期 |

两百多年来，六轮康波（K1 蒸汽到 K6 人工智能，全表见[深潜篇](25-深潜-康波元周期与千日窗口.md)）反复验证同一件事：所有大级别的财富转移都发生在新旧周期的交界处。讲授现场还给过一个人口学的对照记法——「婴儿潮出生年 + 42」大致对应一国消费与经济的峰值年份，中国的两波婴儿潮恰好对上了本世纪初的起飞与前几年的见顶。周期不是玄学，是可以拿日历验证的结构。

**时代维：这一次为什么不同。** 前五轮康波与第六轮的差别，不是「又一项新技术」，而是杠杆的载体换了：

| 对照项 | 前五轮康波（K1–K5） | 第六轮康波（K6） |
|---|---|---|
| 本质 | 工具升级 | 杠杆载体切换 |
| 放大对象 | 碳基人的体力与效率 | 硅基智能直接承担认知工作 |
| 判断问句 | 我有没有用上新工具？ | 这个行业的关键流程是否已因 AI 换了承担者？ |
| 可见信号 | 效率提升百分比 | 十步变一步；按过程收费变按效果收费；专家能力被产品化 |
| 个体形态 | 岗位分工 | 一人即部队 → 一人即品类 → 一人即帝国 |

所以「我用了 AI」不是借势，「我的行业因为 AI 换了杠杆载体」才是。我们此刻正站在 K5 深冬与 K6 初春的叠加带上，**2025–2028 是第六轮康波的千日窗口**——品类定义权在这一窗口内分配。

**体系维：从元周期推到入口的四层望远镜。** 势不能直接变成生意，必须逐层聚焦：

| 层 | 看什么 | 工具 | 产出 |
|---|---|---|---|
| 宏周期势 | 站在哪轮康波、哪个季节、哪个窗口 | 康波分期、技术 S 曲线 | 大时间判断 |
| 中结构势 | 哪个结构变化正在替我开门 | PEST/PESTEL、产业链图 | 结构切片 |
| 微入口势 | 谁的心智松动、预算在迁移 | 心理账户、甜用户、渠道窗口 | 初始进入点 |
| 合力匹配 | 这股势是否刚好放大我的母体 | 母体定义卡、非对称优势 | 借势/不借的最终裁决 |

前三层望远镜倍数递增，最后一层是照妖镜：不是所有大势都是你的势，只有能放大你这颗母体的势，才配叫原力借势。这一层直接调用 [T1 · 非对称优势](../05-threads/T1-非对称优势.md)——势放大的必须是你难以被模仿的那部分，否则势越大，你被替代得越快。

## ④ 新植入

正典一句话定义：

> 原力借势，是判断这个时代为什么现在需要我的原力，并找到最适合进入市场的势能窗口。

第一性问题：**这个时代为什么现在需要我？**

原子模块（全量）：

| 模块 | 内容 |
|---|---|
| B1.1 宏周期势 | 康波、技术范式、资本周期、AI渗透率 |
| B1.2 中结构势 | 政策、经济、社会、技术、产业价值链 |
| B1.3 微入口势 | 用户心智、心理账户、渠道窗口、预算迁移 |
| B1.4 合力匹配 | 我的原力是否刚好适配这股势 |
| B1.5 时间窗口 | 早、刚好、晚，分别对应不同打法 |
| B1.6 势能排序 | 多个机会如何排序 |

判断标准（全量）：

| # | 判断标准 |
|---|---|
| 1 | 是否只是热闹风口？ |
| 2 | 是否存在中长期结构变化？ |
| 3 | 是否与我的原力同向？ |
| 4 | 是否有明确入口和预算迁移？ |

输入是 A4 交来的创业输入包，加上行业趋势、用户变化与政策/技术/渠道信号；输出是势能地图、机会假设、入场窗口判断、机会优先级与一张原力借势卡。通关的手感可以压成五个「能」：能三十秒说清借的是哪股势；能拿出至少三类互相独立的证据；能讲明白为什么是现在而不是前后三年；能证明这股势与母体同向而非硬蹭；能给出明确进入点——甜用户、贵任务、预算来源、品类机会。五个「能」齐了，进 [B2 · 品类独创](22-B2-品类独创.md)。

B1 的输出物不进抽屉：势能地图、机会假设与优先级排序写回 **C3 · 一张地图**的机会地图，成为此后一切取舍判断的输入；入场窗口的裁决过程（尤其是「为什么不借」的否决记录）写回 **A2 · 回到母体**的长期承诺与战略边界——每一次对假势的拒绝，都是对母体边界的一次加固。全局回写关系见[十二模块递归回写图](../50-spine/52-十二模块递归回写图.md)。

## ⑦ 自诊三问

1. 你能在三十秒内说出你正在借的那股势，并给出康波/技术/产业/PEST 中至少三类证据吗？
2. 你能说清「为什么是现在」——三年前为什么不行、三年后为什么太晚吗？
3. 这股势是否明确放大你的母体，而不是你在追着它跑？

三问全「是」，进 B2；第 3 问答「否」，回 A 线重对母体——那是合力问题不是势的问题；前两问答「否」，本关未过，别急着做产品。完整分诊见[自诊 · 你卡在哪一关](../50-spine/53-自诊-你卡在哪一关.md)。

## ⑧ 高弧光

[母公理ʸx](../00-canon/02-母公理ʸx.md)说：做会自我繁殖的事。借势是这条公理在时间轴上的投影——你个人的努力只是乘积里的一个因子，选对季节，是让世界替你完成另一半乘法。

所以借势的底色不是投机，是谦卑，也是自尊。谦卑在于承认：你再强，也强不过季节；自尊在于坚持：再大的势，配不上你的母体就不借。窗口不挑幸运儿，它只挑那些早已把合力备好、并且诚实回答了「这个时代为什么现在需要我」的人。你不必造风，你只需要在风来的方向，站成你自己。
