# 十二模块总图

> 一句话导航：**找到母体，获得原力；借势创业，锁定壁垒；写成文脉，装成系统。** 三部各四步，三四得十二。本页是全仓索引锚——每个模块一行，四个字段（定义 / 不是它 / 第一性问题 / 回写位置），行行可跳转到模块正篇。术语一律以 [83-术语表](../80-governance/83-术语表.md) 为准。

## 1. 为什么恰好是四四四：MECE 论证摘要

四四四不是排版洁癖，是三道 MECE 检验的结果。04c 给出金字塔判据：上层是否统摄下层、下层是否穷尽上层、同层是否互斥、每模块是否有输入判断输出接口、整体是否能递归回写。逐层过一遍：

**为什么是三部？** 母公理 [ʸx](./02-母公理ʸx.md) 的主语是「你」，而「你」的自我繁殖必须同时解答三个正交问题：你是谁（向内·人）、你如何进入世界（向外·事）、你如何让每次进入都让下一次更强（向上·法）。内 ≠ 外 ≠ 上，人 ≠ 事 ≠ 法——互斥；找到你 + 变现你 + 系统你，穷尽了一个人自我繁殖的全部方向——完备。所以是三部，不多不少。

**为什么每部是四步？** 每部内部是一条严格串行的动作链，每步输出恰好是下一步输入，抽掉任何一步链条即断：

- A 线四步是资产的生成次序：先识别（发现）、再对齐（回到）、再激活（获得）、再验证（显化）。识别之前无从对齐，激活之前无从验证——次序不可换，且没有第五个不可归并的动作。v0.8 的裁决是把旧七阶（清算→返源→成形→外化→验证→回写→复利）压缩为四个更高阶动作：清算并入发现，回写与复利上提为贯穿机制。
- B 线四步是生意的通关次序：先判势（何时进）、再命名（如何被认出）、再造容器（如何复利）、再筑墙（如何守住）。四道生死端口各解一题，互不重叠。
- C 线四步是系统的装配次序：先立灵魂（一纸文脉）、再建记忆（一个大脑）、再成判断（一张地图）、再通行动（一条链路）。03a 的病理反证：没有文脉，大脑是杂物箱；没有大脑，地图是空想图；没有地图，链路是瞎执行；没有链路，地图停在认知层。

**递归回写为什么不是第十三个模块？** v0.8 的关键裁决：回写不是任何一部的「第五步」，而是贯穿十二步的底层机制——它是 ʸx 本身在结构里的化身，把它列为模块反而降维。详见 [04-总飞轮](./04-总飞轮.md)。
