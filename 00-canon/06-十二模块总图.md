# 十二模块总图

> 一句话导航：**找到生成你的源头，把它炼成资产；让世界认出并放大它；再把结果写进系统，让下一轮更强。**

三部各四步，三四得十二。本页是全仓索引锚。术语一律以 [83-术语表](../80-governance/83-术语表.md) 为准；本页只负责公开叙事投影，不取得上游 Soul 法权。

## 1. 为什么仍然是三部十二模块

三部回答三个不可省略的问题：

```text
自我：差异价值从哪里持续产生？      → 原力资产
世界：差异价值如何被接受、交换、放大？→ 原力创业
时间：有效结果如何积累并让下一轮更强？→ 原力OS
```

正式骨架不变：

```text
原力战略三部曲
├─ 第一部：原力资产
│  ├─ A1 发现母体
│  ├─ A2 回到母体
│  ├─ A3 获得原力
│  └─ A4 显化原力
├─ 第二部：原力创业
│  ├─ B1 原力借势
│  ├─ B2 品类独创
│  ├─ B3 模式升维
│  └─ B4 壁垒锁定
└─ 第三部：原力OS
   ├─ C1 一纸文脉
   ├─ C2 一个大脑
   ├─ C3 一张地图
   └─ C4 一条链路
```

递归回写不是第十三模块，而是贯穿十二模块的运行机制。

## 2. 第一部：母体是根，资产是终态

第一部最新教学动作链：

```text
A1 找源 → A2 归源 → A3 炼源 → A4 证源
```

它不替换正典模块名，只解释四步究竟发生了什么状态迁移：

```text
表层能力 / 标签 / 事件碎片
→ 母体候选
→ 经校准的母体
→ 可调用原力
→ 经现实选择初步验证的原力资产
```

### 四个跨时代第一性问题

1. **A1：什么持续生成我的不同？**
2. **A2：哪些东西真正属于我，哪些只是外界塑造？**
3. **A3：如何把潜在生成结构训练成真实能力？**
4. **A4：这种原力进入真实世界后，是否真正创造价值？**

旧表达仍可保留，但必须处在正确层级：

```text
“AI 清算之后还剩什么？” → A1 时代教学钩子
“什么保留、什么停止？” → A2 操作层问题
“五种能力如何外化？” → A3 表现层问题
“世界是否需要它？” → A4 教学钩子
```

## 4. B4 唯一壁垒口径

本仓旧版曾保留过“六层壁垒”的历史表达，现正式清理。

唯一有效的四类壁垒：

| 壁垒 | 控制权 | 最高形态 |
|---|---|---|
| **虚壁垒** | 心智控制权 | 别人能学你的表达，但抢不走你的解释权 |
| **实壁垒** | 交付控制权 | 别人能模仿卖点，但复刻不了交付系统 |
| **入壁垒** | 入口控制权 | 入口、信任与传播持续自增强 |
| **出壁垒** | 留存控制权 | 用户因成果、关系、习惯、数据与共建持续留下 |

```text
飞轮 = 四种控制权相互强化的机制，不是第五类壁垒。
母体 = 四种控制权持续生成差异的源头，不是第六类壁垒。
```
