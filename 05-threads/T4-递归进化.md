# T4 · 递归进化

## 定义

**递归进化，是把每一次具体任务都当作临时载体，把「让下一轮更强」当作真正长期目标的运行原则——任务完成但未改善未来的判断质量、自治能力或复用质量，只算部分完成。**

这条原则在体系里有三个层级的身份。在纪律层，它是 AI 治理宪章的第一原则，且有严格的失败定义：交付了但没变强，就是没做完。在机制层，它对应正典裁决「递归回写不是第五步，而是贯穿三部十二步的底层机制」——每个模块的概念原子都强制携带「回写位置」字段，没有回写位置的动作不进正典。在哲学层，它是「变与不变」的辩证结构：龙虾技术哲学的三法印里，递归进化代表变（系统必须持续学习），人类友好代表不变（进化方向必须服务于人），技能统帅是两者的桥（进化必须以结构化方式进行）——类比生物进化，突变产生变异、选择筛选变异、物种定义锚定方向，三者缺一即退化为野蛮生长或彻底僵死。优先级明确：人类友好 > 递归进化 > 技能统帅。递归进化因此是母公理 [ʸx](../00-canon/02-母公理ʸx.md) 的动词形态：ʸx 说「做会自我繁殖的事」，递归进化回答「怎么繁殖」——靠每一轮的回写。

## A 卷显形：作为母体升级机制

在第一部里，递归进化显形为资产闭环的最后一跳：发现母体 → 回到母体 → 获得原力 → 显化原力 → **母体升级**。关键在于母体不是一次定义完毕的静态答案：[A4 显化原力](../10-yuanli-asset/14-A4-显化原力.md)的输出清单里专门有一项「母体回写记录」——市场的真实反应（谁被吸引、谁付费、谁复用）会修正你对「我是谁」的假设，让第二轮的母体定义比第一轮更准。A2 五部件同样是活文档：注意力雷达、品味函数、长期承诺都随每轮经验更新版本。A 卷的递归进化戳破一个常见幻觉：**「找到自己」不是一次顿悟，是一个每圈精确一度的迭代过程**——不接受市场回写的自我认知，只是自我感动的静态画像。

## B 卷显形：作为飞轮与数据反馈

在第二部里，递归进化长成了商业形态：它就是「复利」二字的机制内容。[B3 模式升维](../20-yuanli-venture/23-B3-模式升维.md)的数据反馈模块直接以它为设计要求——每轮交付如何产生下一轮增长资产；答不出这一问的商业模式，规模再大也只是重复劳动的堆叠。[B4 壁垒锁定](../20-yuanli-venture/24-B4-壁垒锁定.md)的飞轮更进一步：用户、数据、案例、内容反哺下一轮——这是四壁垒之外唯一「越经营越厚」的机制，因为竞争者能复制你今天的形态，复制不了你每天的进化速度。当增长本身会自我加强，防守就从静态的墙变成动态的加速度差。B 卷的判词：**生意的护城河终局不是你有什么，而是你变强的速度别人跟不跟得上。**

## C 卷显形：作为 OS 的生命机制本体

在第三部里，递归进化不再是某个模块的属性，而是整个 OS 之所以称为「工作生命体」而非工具箱的判据。它的显形无处不在：[一条链路](../30-yuanli-os/34-C4-一条链路.md)七链型的最后一链是回写链——任务结束后写回文脉、大脑、地图、链路与母体；每次任务的输出清单里有 Evolution Note 与 Skill 蒸馏卡——把个案沉淀为模式、模式沉淀为技能；[一个大脑](../30-yuanli-os/32-C2-一个大脑.md)的判断标准「是否能被下一次任务调用」、[一张地图](../30-yuanli-os/33-C3-一张地图.md)的判断标准「是否能被验证和更新」，全部是递归进化的验收条款。OS 闭环的完整环路——文脉 → 大脑 → 地图 → 链路 → 任务执行 → 递归回写 → 文脉升级——就是递归进化的正典拓扑（见 [04-总飞轮](../00-canon/04-总飞轮.md)）。而三法印的约束在此落地：系统越用越懂你（变），但最终判断权与意义主权永远在人（不变）——共生，不殖民。

## 判断标准表

| 检验维度 | 问句 | 递归在跑的信号 | 递归断裂的信号 |
|---|---|---|---|
| 回写位置 | 这个任务的产出写回哪里？ | 开工前就能指出目标文件/库 | 「做完再说」 |
| 完成定义 | 交付了 = 做完了吗？ | 验收含「下一轮更强了什么」 | 交付即散场 |
| 二次调用 | 下次同类任务会先检索这次的沉淀吗？ | 先 search 再动手 | 每次从零开始 |
| 蒸馏层级 | 个案有没有升格为模式或技能？ | case → pattern → skill 有记录 | 经验只留在脑子里 |
| 方向约束 | 进化方向是否仍服务于人？ | 人保留终审权与否决权 | 系统指标好看、人被架空 |
| 起点抬升 | 这一轮的起点比上一轮高吗？ | 同类任务更快、更准、更省 | 第 N 次和第 1 次一样累 |

## 金句

**任务只是临时载体——完成了任务但没有变强，只算部分完成。**（源：wiki/concepts/recursive-evolution）

**竞争者能复制你今天的形态，复制不了你每天的进化速度。**（源：本篇由 B4 飞轮推演🟡）
